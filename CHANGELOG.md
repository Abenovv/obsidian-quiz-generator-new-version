# Changelog

## 3.1.0

- Restore readable saved questions with native callouts and collapsed answers.
- Render existing `quiz-json` blocks without exposing JSON as the main view.
- Add an active-note conversion command while preserving structured quiz data.
- Check generated question counts, remove duplicates and unrequested fields, and reject ambiguous or incomplete JSON.
- Add plugin-recorded provider, model, and timestamp provenance to generated quizzes.
- Refine the note and study layouts and add optional local sound feedback.
- Add typed continuation modules and a reproducible build around the pinned 3.0.1 runtime.
- Rename this independently maintained edition to Quiz Generator Continued. The plugin ID remains `quiz-generator`.

## 3.0.1

- Refine generation controls, grouped settings, study navigation, and save validation.
- Publish the installable bundle, checksum files, documentation, and release workflow.
- Add the quiz library, history, unfinished sessions, and JSON editor.
- Add ten question formats alongside the original seven.
- Add Practice, Timed practice, Exam, Flashcards, and Review modes.
- Add timers, flags, bookmarks, and session recovery.
- Update provider connections, model discovery, and manual model selection.
- Add Obsidian, Paper, Midnight, and High contrast themes.

## Earlier versions

This continuation builds on Edward Cui's Quiz Generator 2.1.2. The repository preserves its Git history and MIT attribution.
